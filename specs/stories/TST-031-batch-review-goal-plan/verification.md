* `writeArtifactExclusive's link-based exclusive create (M-4) assumes the target filesystem supports hard links across the Goal Plan directory. On a filesystem that does not (exFAT, some FUSE mounts, some network mounts), every link call fails and every review goal-plan run reports ERROR, exit 3, even on an otherwise-healthy, unconflicted batch — there is no fallback to a non-hard-link exclusive-create strategy.`
* `A process crash or kill between the successful link and the subsequent unlink of the temp file leaves a stray .<uuid>.goal-plan.tmp hard link inside goal-plan/<plan.id>/. This is not a REVIEW_GOAL_PLAN_CONFLICT (the temp file's name never collides with a real artifact name) and a later run is unaffected, but the stray file pollutes the directory ForgePilot's goal preflight reads and shows up in git status until removed by hand.`
* `On macOS (and likely other BSD-derived link() implementations), link() can follow a symlink placed at the temporary file's own path if it were swapped in between close() and link() — the same class of TOCTOU as the parent-directory race above, and, like it, requires an attacker or concurrent process with write access to the repository working tree at exactly that moment; the temp file's own randomized name makes this substantially harder to target than the fixed final artifact names, but it is not eliminated by this code.`
* `Node has no openat-style path-relative open primitive: the symlink re-check after mkdir (writeGoalPlanArtifacts) still leaves a window between that check and each artifact's own open/link call where a parent directory segment could be swapped for a symlink. This is a pre-existing class of race in this codebase (review-records.ts's createNewRecord has the same shape) and is not fully closable in Node without a lower-level syscall binding.`
* `No run of review goal-plan through the packed/built CLI executable itself (spawnSync against packages/cli/dist/bin.js, as e.g. root-and-bin.test.mjs does for other commands) exists yet; all coverage calls the built module's exported functions directly. review observe and the ForgePilot rehearsal (the Story after this one) are out of scope here per the Story's own Out of Scope section; this Story's artifacts have never been fed to a real ForgePilot goal preflight.`
