# ForgeFlow 0.4.1

This Additive pre-1.0 release provides optional Codex project activation.
Preview `scripts/codex-activate <repository>` and authorize `--apply` to install
a pinned local forgeflow skill and a bounded AGENTS.md entry point. Existing
bootstrap, upgrade, Doctor, and verification behavior remains compatible.

No adopter migration is required. See [activation setup and rollback](../codex-activation.md)
and [versioning](../../protocol/versioning.md). Installation does not execute
adopter code or guarantee implicit model invocation. Human Review retains its
authority; live Codex walkthrough evidence is separate from automated checks.
