For implementation requests or "continue development" / "繼續開發", first locate
the repository root (in Git, use `git rev-parse --show-toplevel`). Read that
root's `.agents/skills/forgeflow/SKILL.md` and follow its project-local entry
workflow. A missing path under the current subdirectory is not a missing skill;
check the root path before diagnosing installation. General questions and
discussion do not start
a Story workflow. `$forgeflow` is the explicit fallback. If that local skill is
missing or instructions conflict, report the concrete issue and proposed repair;
continue independent work without silently reinstalling or changing project rules.
